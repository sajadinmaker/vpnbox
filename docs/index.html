VPNBOX

A free VPN for Linux. No account, no key, no payment. One Python file, standard library only, built on the VPN Gate volunteer relay experiment (University of Tsukuba).

tar -xzf vpnbox-1.0.0-beta.tar.gz
cd vpnbox-1.0.0-beta
sudo ./install.sh

About

  • Fetches the live volunteer server list and ranks it by reachability
  • Connects through OpenVPN — full tunnel, leak-safe DNS via systemd-resolved

Commands: vpn (menu), vpn refresh, vpn countries, sudo vpn connect, vpn status, sudo vpn disconnect

Connect

  • sudo vpn connect — fastest server, anywhere
  • sudo vpn connect --country JP --city chiyoda — pick country / city
  • sudo vpn connect --site meta --office all — appear near a platform office
  • vpn status / sudo vpn disconnect
