VPNBOX

A free, open-source VPN client for Linux. No account, no key, no payment. vpnbox reads the live volunteer server list of the VPN Gate academic experiment (University of Tsukuba), ranks it by reachability, and connects through OpenVPN — one Python file, standard library only.

Install

tar -xzf vpnbox-1.0.0-beta.tar.gz
cd vpnbox-1.0.0-beta
sudo ./install.sh

Requires OpenVPN 2.5+, systemd-resolved, and Python 3.8+. Remove with sudo ./uninstall.sh.

Usage

vpn refresh                          # fetch the live server list
vpn countries                        # what is reachable right now
sudo vpn connect                     # fastest server, anywhere
sudo vpn connect --country JP --city chiyoda
sudo vpn connect --site meta --office all
vpn status                           # exit IP and location
sudo vpn disconnect

Connections use sudo because routes and DNS are system state. Dead volunteer servers fail over automatically; the reported exit IP is verified against the server you asked for.

Platform offices

A distinctive feature of vpnbox is office-relative exit targeting: 29 platforms, 239 offices and 31 countries are geocoded via OpenStreetMap, and connections are ranked by distance tier, ping and speed.

--site <platform> targets a platform's primary HQ; --office <city> selects any other office; --office all picks the server nearest to any office worldwide.

Relevant considerations

  • Volunteer servers change hourly — run vpn refresh before connecting.
  • Logging policy is set by each relay operator; VPN Gate publishes that field for every server.
  • There is no kill switch: if OpenVPN exits abnormally, traffic resumes through your normal connection — impose a firewall policy (e.g. ufw allowing outbound on the tunnel interface only) if that matters to you.
